# ADV3 スマートフォン対応版

ADV2を複製して作成した独立版です。画像、音声、シナリオ、参考資料も同梱しています。

## 起動

パソコンでは `index.html` をブラウザで開いてください。iPhoneではADV3フォルダ一式を静的Webサーバーに配置し、Safariでアクセスして横向きにしてください。ビルドや追加ライブラリは不要です。

## 変更内容

- 852 × 393を基準に、右コマンド・左上画像・左下セリフをCSS Gridで配置。
- `viewport-fit=cover`、Safe Area、動的ビューポート高（dvh）に対応。
- コマンドとセリフは16px。コマンド行は高さ44px以上。
- 画像の縦横比を維持。背景は領域を埋めるため周囲をトリミングし、キャラクターは比率を維持して表示。
- 実際のセリフ領域と文字幅を測定してページ分割。▼表示後にセリフ領域をタップすると次へ進む。
- 表示中の回転などで文章が収まらなくなった場合はセリフ領域をスクロール可能。
- 「もちもの」で取得済みアイテムを確認可能。
- STARTをボタン化し、キーボード操作とフォーカス表示を整備。
- サブメニュー、追加コマンド、エンディングは必要に応じて内部スクロール。

利用可能な高さが7行 × 44pxと枠線の合計を下回る場合は、タップ領域を維持するためコマンド欄をスクロールできます。縦向きでも左右構造を維持しますが、横向きを推奨します。

## 確認

ヘッドレスChromeで852 × 393、667 × 375、568 × 320、844 × 390、932 × 430、1024 × 768、393 × 852を確認。横幅のはみ出し、7コマンドの高さ、場所移動、もちもの表示、キャラクター表示、エンディングを検証しました。

iPhone実機のSafari、実際のノッチ・ブラウザバー、音声出力は未確認です。
